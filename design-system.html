Responsive y reglas de uso

  • Escritorio (> 1024 px): grilla de Bootstrap a dos columnas, collage y mesas con elementos libres.
  • Tableta (≤ 1024 px y ≤ 860 px): las columnas se apilan, el menú pasa a hamburguesa y se ocultan decoraciones que tapan títulos.
  • Móvil (≤ 600 px): una columna, mesas más altas con fotos en dos columnas y bordes de sección más finos.
  • Movimiento reducido: si el sistema lo pide, las animaciones se desactivan y todo el contenido queda visible.
  • Uso de color: ciruela para acciones y títulos, salvia para acentos en itálica, crema y papel para fondos; salvia-700 para textos pequeños (contraste).
  • Uso tipográfico: un solo título Display por página; itálica DM Serif solo para la palabra que se quiere destacar.
